Escalabilidad del Sistema

Ventajas de la escalabilidad vertical

Entre las principales ventajas de este enfoque se encuentran: Simplicidad en la administración del sistema...

Entre las principales ventajas de este enfoque se encuentran:

  • Simplicidad en la administración del sistema.
  • Menor complejidad arquitectónica.
  • Facilidad para implementar mejoras de rendimiento.

Estos factores hacen que la escalabilidad vertical sea una estrategia adecuada para sistemas de tamaño pequeño o mediano.

Limitaciones de la escalabilidad vertical

A pesar de sus ventajas, este enfoque presenta algunas limitaciones importantes...

A pesar de sus ventajas, este enfoque presenta algunas limitaciones importantes:

  • Existe un límite físico en la capacidad del hardware.
  • El costo del hardware de alto rendimiento puede ser elevado.
  • El sistema continúa dependiendo de un único servidor.

Debido a estas limitaciones, los sistemas que manejan grandes volúmenes de datos suelen adoptar enfoques basados en escalabilidad horizontal.

Escalabilidad horizontal

La escalabilidad horizontal, también conocida como scale-out, consiste en aumentar la capacidad del sistema...

La escalabilidad horizontal, también conocida como scale-out, consiste en aumentar la capacidad del sistema mediante la incorporación de múltiples servidores que trabajan de manera conjunta para procesar las solicitudes de los usuarios.


En este enfoque, los datos y las operaciones se distribuyen entre varios nodos del sistema, lo que permite repartir la carga de trabajo y mejorar la capacidad de procesamiento global.
